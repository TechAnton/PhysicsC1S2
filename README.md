# Physics C1S2 — подготовка к экзамену

Материалы по 42 билетам физики (электродинамика, оптика, квантовая и ядерная физика).

## Структура

```
PhysicsC1S2/
├── lectures/        Подробные конспекты по каждому билету (01–42)
├── lectures_shorts/ Кратко: 2–3 абзаца на билет (минимум для зачёта)
├── exam-prep/       Планы, шпаргалки, ответы для экзамена
└── README.md        Этот файл
```

## С чего начать

1. **[exam-prep/00_план_подготовки.md](exam-prep/00_план_подготовки.md)** — план на 3 дня, приоритеты, видео.
2. **[exam-prep/01_шпаргалка_формулы.md](exam-prep/01_шпаргалка_формулы.md)** — все формулы.
3. **[exam-prep/02_ответы_за_2_минуты.md](exam-prep/02_ответы_за_2_минуты.md)** — что сказать на экзамене.
4. **[exam-prep/03_карта_билетов.md](exam-prep/03_карта_билетов.md)** — навигация по билетам.
5. **[exam-prep/шпаргалка.html](exam-prep/шпаргалка.html)** — HTML-шпаргалка на все 42 темы (браузер/телефон).

Подробная теория — в `lectures/`. Кратко выучить — в `lectures_shorts/` (по 2–3 абзаца).
