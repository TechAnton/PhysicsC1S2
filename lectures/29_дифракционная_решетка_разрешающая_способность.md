# 29. Дифракционная решётка. Разрешающая способность дифракционной решётки. Дифракция в технике

---

## Что сказать на экзамене (кратко)

> Дифракционная решётка — много параллельных щелей с периодом d. Условие максимума: d sinφ = kλ. Разрешающая способность R = λ/Δλ = Nk (N — число щелей, k — порядок спектра). Решётка разделяет цвета лучше призмы, используют в спектрометрах. Дифракция в технике: оптика, радио, антенны, CD/DVD.

---

## 1. Что такое дифракционная решётка?

### Определение

**Дифракционная решётка** — оптический элемент с **большим числом** N параллельных **одинаковых** щелей (или штрихов), разделённых расстоянием **d** (период, **постоянная решётки**).

```
    вид сверху:
    
    ║ ║ ║ ║ ║ ║ ║ ║  ← штрихи (или щели)
    ←─ d ─→
```

### Отличие от двух щель Юнга

| Юнг | Решётка |
|-----|---------|
| 2 щели | **сотни–тысячи** |
| широкие полосы | **узкие** яркие максимумы |
| плохо разделяет цвета | **отлично** разделяет λ |

**На пальцах:** Юнг — два голоса. Решётка — хор из 1000 человек — звук (свет) **чище** и **острее** по направлению.

## 2. Дифракция Фраунгофера на решётке

Источник и экран **далеко** → падающие лучи **параллельны** → формулы Фраунгофера.

Падающий луч под углом, отражённые/прошедшие лучи под углом φ к нормали.

### Условие максимума (главная формула!)

$$\boxed{d\sin\varphi = k\lambda}$$

| Символ | Значение |
|--------|----------|
| d | период решётки (расстояние между щелями) |
| φ | угол максимума |
| k | порядок спектра (0, ±1, ±2, …) |
| λ | длина волны |

### На пальцах

Разность хода между соседними щелями = **d sin φ**. Если она равна **целому** числу λ → все щели **в фазе** → яркий максимум.

### k = 0

φ = 0 — **нулевой** максимум (прямо вперёд), без разделения цветов.

### k = ±1, ±2…

**Спектры** первого, второго порядка — разные цвета под разными углами.

```
         k=0
          ↑
    ╲  k=-1  k=+1  ╱
     ╲   ↙   ↘   ╱
      ╲________╱
         решётка
```

---

## 3. Пример расчёта угла

**Дано:** d = 2 мкм = 2·10⁻⁶ м, λ = 600 нм = 6·10⁻⁷ м, k = 1.

$$\sin\varphi = \frac{k\lambda}{d} = \frac{6 \cdot 10^{-7}}{2 \cdot 10^{-6}} = 0{,}3$$

$$\varphi \approx 17{,}5°$$

Красный (λ больше) — φ больше; синий — меньше → **радуга** в спектре.

---

## 4. Разрешающая способность

### Что это?

Способность **различить** две близкие длины волн λ и λ + Δλ.

$$\boxed{R = \frac{\lambda}{\Delta\lambda} = Nk}$$

| Символ | Значение |
|--------|----------|
| R | разрешающая способность (безразмерная) |
| N | **число** щелей (штрихов), участвующих в луче |
| k | порядок спектра |

### На пальцах

- **Больше щелей** N → уже пик → ближе линии спектра **различаются**.
- **Выше порядок** k → лучше разрешение, но слабее яркость.

### Пример

N = 10000, k = 1:

$$R = 10000 \quad \Rightarrow \quad \Delta\lambda = \frac{\lambda}{10000}$$

Для λ = 600 нм: Δλ = 0,06 нм — очень близкие линии видны.

### Рэлеевский критерий (для справки)

Две линии считают разрешёнными, если максимум одной совпадает с минимумом другой. На экзамене чаще **R = Nk**.

---

## 5. Решётка vs призма

| | Призма | Решётка |
|---|--------|---------|
| Разделение цветов | дисперсия n(λ) | дифракция d sinφ = kλ |
| Линейность | нелинейно | **линейно** по λ |
| Разрешение | среднее | **высокое** (большое N) |
| Потери | есть | меньше в нужный порядок |

Спектрометры в лаборатории — обычно **решётка**.

---

## 6. Дифракция в технике

| Область | Применение |
|---------|------------|
| **Спектрометрия** | анализ состава (звёзды, химия) |
| **Очки, линзы** | предел резкости — дифракция на зрачке |
| **Микроскоп** | дифракционный предел ~λ |
| **CD, DVD, Blu-ray** | штрихи = решётка, лазер читает отражённые порядки |
| **Голография (30)** | дифракция на записанной структуре |
| **Радио, антенны** | огибание, решётки антенн |
| **Рентген** | кристалл = 3D решётка, дифракция на атомах |
| **Волоконная оптика** | моды, дифракция на неровностях |

### CD как решётка

Период дорожки ~ 1 мкм, лазер λ ~ 0,8 мкм → отражённый луч под углом → считывание «питов» и «ландов».

## 7. Типы решёток

| Тип | Описание |
|-----|----------|
| **Прозрачная** (щели) | свет проходит |
| **Отражающая** (штрихи) | свет отражается |
| **Эшелле** | ступеньки, высокое разрешение |
| **Голографическая** | записана интерференцией |

## Шпаргалка

| Что | Формула |
|-----|---------|
| Максимум | $d\sin\varphi = k\lambda$ |
| Разрешение | $R = \lambda/\Delta\lambda = Nk$ |
| k = 0 | центральный максимум |
| k = ±1 | первый порядок спектра |

### Три фразы для экзамена

1. «Дифракционная решётка: d sinφ = kλ — условие максимума.»
2. «Разрешающая способность R = Nk — больше щелей, лучше различение λ.»
3. «Применение: спектрометры, CD/DVD, анализ веществ и звёздного света.»
