# 39. Теория Бора. Атом водорода по Бору

---

## Что сказать на экзамене (кратко)

> Модель Бора (1913): электрон на дискретных орбитах, на которых не излучает; переходы между уровнями — кванты hν. Постулаты: 1) стационарные орбиты с mvr = nh/(2π); 2) излучение только при переходах; 3) E_n = -13,6/n² эВ. Спектр водорода объяснён. Ограничение: полуклассическая модель, не объясняет многоэлектронные атомы.

---

## 1. Проблема классической модели атома

### Модель Томсона («булочка с изюмом»)

Электроны внутри положительного шара — **не** объясняла спектры.

### Модель Резерфорда (ядро + электроны)

Электрон кружит вокруг ядра → **ускорение** → по классике должен **излучать** энергию → **упасть** на ядро за ~10⁻¹⁰ с!

**Атомы же стабильны** → нужна **квантовая** идея.

---

## 2. Постулаты Бора (три штуки)

### Постулат 1: Стационарные орбиты

Электрон движется по **определённым** орбитам (стационарным), на которых **не излучает** энергию.

На стационарной орбите **момент импульса** квантуется:

$$\boxed{mvr_n = n \frac{h}{2\pi} = n\hbar}$$

| Символ | Значение |
|--------|----------|
| n | **главное квантовое число** n = 1, 2, 3, … |
| m | масса электрона |
| v | скорость на орбите |
| r_n | радиус n-й орбиты |
| ℏ = h/(2π) | постоянная Планка, редуцированная |

**На пальцах:** только «разрешённые» орбиты, как ступеньки лестницы, а не любой радиус.

### Постулат 2: Излучение при переходах

Атом излучает (или поглощает) **только** при **переходе** с одной стационарной орбиты на другую:

$$h\nu = E_i - E_f$$

E_i — энергия начального уровня, E_f — конечного.

**На пальцах:** электрон «прыгает» между ступеньками — при прыжке вниз выбрасывает фотон hν.

### Постулат 3: Соответствие классической и квантовой теории (корреспонденция)

При больших n поведение близко к классическому. На экзамене реже спрашивают.

---

## 3. Радиусы и энергии орбит водорода

### Радиус n-й орбиты

$$r_n = n^2 r_1$$

$$r_1 \approx 0{,}53 \cdot 10^{-10} \text{ м} = 0{,}53 \text{ Å}$$

**Боровский радиус** — r₁.

| n | r_n (примерно) |
|---|----------------|
| 1 | r₁ = 0,53 Å |
| 2 | 4r₁ = 2,12 Å |
| 3 | 9r₁ |

### Энергия n-го уровня

$$\boxed{E_n = -\frac{13{,}6}{n^2} \text{ эВ}}$$

или в джоулях:

$$E_n = -\frac{2{,}18 \cdot 10^{-18}}{n^2} \text{ Дж}$$

**Минус** — электрон **связан** с ядром (нужна энергия, чтобы вырвать).

| n | E_n (эВ) |
|---|----------|
| 1 | -13,6 (основное состояние) |
| 2 | -3,4 |
| 3 | -1,51 |
| ∞ | 0 (ионизация) |

**Энергия ионизации** водорода: 13,6 эВ — чтобы вырвать электрон с n=1.

---

## 4. Спектр водорода

### Серия Бальмера (переходы на n=2)

Видимый свет:

$$\frac{1}{\lambda} = R\left(\frac{1}{2^2} - \frac{1}{n^2}\right), \quad n = 3, 4, 5, \ldots$$

R — постоянная Ридберга ≈ 1,097·10⁷ м⁻¹.

### Общая формула

$$\boxed{h\nu = E_n - E_m = 13{,}6\left(\frac{1}{m^2} - \frac{1}{n^2}\right) \text{ эВ}}$$

где n > m (переход **вниз** — излучение).

### На пальцах

Электрон с n=3 «прыгнул» на n=2 → фотон с энергией E₃ - E₂ → линия спектра (красная Hα и т.д.).

### Пример

Переход 3 → 2:

$$\Delta E = 13{,}6\left(\frac{1}{4} - \frac{1}{9}\right) = 13{,}6 \cdot \frac{5}{36} \approx 1{,}89 \text{ эВ}$$

---

## 5. Схема уровней (наглядно)

```
    E
    0 ─────────────  ионизация (n=∞)
    
    -1,51 ─  n=3
    -3,4  ─  n=2  ← серия Бальмера (сюда падают)
    -13,6 ─  n=1  ← основное состояние
```

Стрелки вниз — излучение фотона.

---

## 6. Успехи и ограничения Бора

### Успехи

- Стабильность атома (не падает на ядро).
- **Спектр водорода** и одноэлектронных ионов (He⁺).
- Квантование mvr.

### Ограничения

- **Полуклассическая** модель (орбиты как в классике, но с правилами).
- Не объясняет **многоэлектронные** атомы, **тонкую** структуру, **спины**.
- Полное объяснение — **квантовая механика** (Шрёдингер, вопрос 40).

---

## 7. Связь с волной де Бройля

На орбите должна укладываться **целое** число длин волн де Бройля:

$$2\pi r_n = n\lambda = n\frac{h}{mv}$$

Отсюда то же mvr = nh/(2π) — **стационарная** волна на орбите!
