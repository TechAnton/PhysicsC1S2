## Раздел 1. Электростатика (1–7)

### 1. Заряд, Кулон, E 🔴
| | |
|---|---|
| Закон Кулона | $F = k\dfrac{q_1 q_2}{r^2}$ |
| Напряжённость | $\vec{E} = \dfrac{\vec{F}}{q_0}$, $E = k\dfrac{\|q\|}{r^2}$ |
| Суперпозиция | $\vec{E} = \sum \vec{E}_i$ |
| k | $9 \cdot 10^9$ Н·м²/Кл² |
| e | $1{,}6 \cdot 10^{-19}$ Кл |

### 2. Гаусс, нить 🔴
| | |
|---|---|
| Теорема Гаусса | $\oint \vec{E} \cdot d\vec{S} = \dfrac{q_{\text{внутр}}}{\varepsilon_0}$ |
| Поле нити | $E = \dfrac{\lambda}{2\pi\varepsilon_0 r}$ |
| Поле плоскости | $E = \dfrac{\sigma}{2\varepsilon_0}$ |
| ε₀ | $8{,}85 \cdot 10^{-12}$ Ф/м |

### 3. Потенциал 🔴
| | |
|---|---|
| Потенциал точки | $\varphi = k\dfrac{q}{r}$ |
| Связь E и φ | $E = -\dfrac{d\varphi}{dr}$ |
| Суперпозиция | $\varphi = \sum k\dfrac{q_i}{r_i}$ |
| Работа | $A = q(\varphi_1 - \varphi_2)$ |
| Напряжение | $U = \varphi_1 - \varphi_2$ |

### 4. Диполь
| | |
|---|---|
| Момент диполя | $\vec{p} = q\vec{l}$ (от − к +) |
| Момент сил | $\vec{M} = [\vec{p} \times \vec{E}]$ |
| Энергия | $W = -pE\cos\alpha$ |

### 5. Проводники 🔴
| | |
|---|---|
| E внутри | 0 |
| E у поверхности | $E = \dfrac{\sigma}{\varepsilon_0}$ |
| Потенциал | одинаковый по всему объёму |

### 6. Ёмкость
| | |
|---|---|
| Определение | $C = \dfrac{Q}{U}$ |
| Шар | $C = 4\pi\varepsilon_0 R$ |
| Земля | $C \approx 700$ мкФ |
| Энергия | $W = \dfrac{CU^2}{2}$ |

### 7. Конденсаторы 🔴
| | |
|---|---|
| Плоский | $C = \dfrac{\varepsilon_0 \varepsilon S}{d}$ |
| Сферический | $C = 4\pi\varepsilon_0 \varepsilon \dfrac{R_1 R_2}{R_2 - R_1}$ |
| Цилиндрический | $C = \dfrac{2\pi\varepsilon_0 \varepsilon L}{\ln(R_2/R_1)}$ |
| Параллельно | $C = C_1 + C_2$ |
| Последовательно | $\dfrac{1}{C} = \dfrac{1}{C_1} + \dfrac{1}{C_2}$ |
