## Стратегия «связать два слова»

На заочном экзамене часто достаточно:

1. **Определение** одним предложением.
2. **Главная формула** (или две).
3. **Пример / опыт** из жизни.
4. **Связь** с соседней темой («это как в билете N, только…»).

Не обязательно выводить формулы — достаточно знать **когда** применять.

## Что учить наизусть (топ-20 формул)

Если совсем мало времени — только это:

```
1.  F = kq₁q₂/r²
2.  E = kq/r²,  ∮EdS = q/ε₀
3.  φ = kq/r,  E = −dφ/dr
4.  C = Q/U,  C = ε₀εS/d
5.  I = Q/t,  I = U/R,  R = ρl/S
6.  I = ε/(R+r),  Q = I²Rt
7.  B = μ₀I/(2πr),  F = qvB,  F = BIl
8.  n₁sinα = n₂sinβ,  sinα₀ = n₂/n₁
9.  Δ = kλ (макс),  Δx = λL/d
10. d sinφ = kλ
11. I = I₀cos²α,  tanα_B = n
12. I = I₀e^(-κx)
13. E = σT⁴,  λ_max·T = 2,9·10⁻³
14. hν = A_вых + E_k
15. λ = h/p
16. E_n = −13,6/n² эВ
17. E_св = Δm·c²
18. N = N₀·2^(-t/T½)
19. E = E₀/ε (диэлектрик)
20. F/l = μ₀I₁I₂/(2πr)
```

## Типичные ошибки (не делай так)

| Ошибка | Правильно |
|--------|-----------|
| Путаешь E и φ | E — вектор силы, φ — скаляр потенциала |
| Путаешь правую и левую руку | **Правая** — направление B; **левая** — сила (Лоренц, Ампер) |
| Конденсаторы как резисторы | У **C** параллельно складываются, последовательно — наоборот |
| T в Цельсиях в E=σT⁴ | Только **Кельвин**: T(K) = t(°C) + 273 |
| Путаешь интерференцию и дифракцию | Интерференция — 2 луча; дифракция — огибание, много лучей |
| Забываешь «работа Лоренца = 0» | Частый вопрос — магнитное поле не меняет E_k |

## Как сдавать устный ответ (шаблон)

```
1. «Тема билета — это …» (определение, 1 предложение)
2. «Основные законы: …» (1–2 формулы)
3. «Физический смысл: …» (аналогия или опыт)
4. «Применение / связь: …» (по желанию)
```

**Пример (билет 8):**  
«Электрический ток — упорядоченное движение зарядов, I = Q/t. Закон Ома: I = U/R. Сопротивление R = ρl/S зависит от длины, сечения и материала. Пример — чайник в розетке 220 В.»
