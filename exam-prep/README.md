# Подготовка к экзамену по физике (C1S2)

Материалы для быстрой подготовки. Лекции по билетам лежат отдельно в `../lectures/`.

## Структура репозитория

```
PhysicsC1S2/
├── lectures/          ← 42 файла по билетам (подробная теория)
└── exam-prep/         ← этот раздел (планы, шпаргалки, ссылки)
    ├── README.md                  ← вы здесь
    ├── 00_план_подготовки.md      ← с чего начать, приоритеты, 3 дня
    ├── 01_шпаргалка_формулы.md    ← все формулы на 5–10 страниц
    ├── 02_ответы_за_2_минуты.md   ← что сказать на экзамене по каждому №
    └── 03_карта_билетов.md        ← таблица: приоритет + ссылка на лекцию
```

## Как пользоваться (кратко)

1. Открой **00_план_подготовки.md** — там порядок изучения и приоритеты.
2. Прогони **01_шпаргалка_формулы.md** — выучи формулы с пометкой 🔴.
3. По каждому билету прочитай блок «Что сказать» в **02_ответы_за_2_минуты.md**.
4. Если тема не зашла — открой подробный файл в `lectures/`.
5. **03_карта_билетов.md** — навигатор: какой файл открыть и насколько важен билет.

## Уровни важности

| Уровень | Значение |
|---------|----------|
| 🔴 **Обязательно** | Формулы + определение + 2 фразы на экзамен |
| 🟡 **Желательно** | Понимать суть, знать главный пример |
| 🟢 **Минимум** | Одно предложение «что это», если времени мало |

## Быстрый маршрут «остался 1 день»

1. Шпаргалка формул (разделы 1–4: электричество, магнетизм, оптика, кванты).
2. Ответы за 2 минуты — все 42 номера (хотя бы прочитать).
3. Углубление только по 🔴 билетам из карты.

Удачи на экзамене.
