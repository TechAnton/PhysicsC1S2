# 9. ЭДС. Закон Ома для полной цепи. Джоуль–Ленц

Сторонние силы. ЭДС. Закон Ома для неоднородного участка цепи. Частные случаи. Закон Джоуля–Ленца

---

Сторонние (неэлектростатические) силы в источнике создают ЭДС ε — работа на единичный заряд при прохождении через источник. Полная цепь: I = ε/(R + r), где r — внутреннее сопротивление источника.

Закон Джоуля–Ленца: Q = I²Rt — при прохождении тока выделяется тепло. Мощность: P = I²R = UI. Холостой ход: I = 0, U = ε. Короткое замыкание: R = 0, I = ε/r.

На экзамене: ε — ЭДС, I = ε/(R+r), Q = I²Rt. Пример: лампочка и нагреватель греются от тока.
