# 10. Магнитное поле. Примеры таких полей. Правило правой руки. Принцип суперпозиции магнитных полей

---

Магнитное поле создают движущиеся заряды (токи) и постоянные магниты. Магнитная индукция B (тесла) характеризует поле. Правило правой руки: у прямого провода — большой палец по I, пальцы обхватывают по B; у соленоида — пальцы по I, большой по B.

Примеры: провод B = μ₀I/(2πr), соленоид B = μ₀nI, виток в центре B = μ₀I/(2R). Суперпозиция: B = B₁ + B₂ + … (векторно). Линии B — замкнутые.
