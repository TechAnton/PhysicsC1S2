# 40. Квантовая теория атомов. Правила заполнения таблицы Менделеева

---

Электроны занимают орбитали (s, p, d, f). Принцип Паули: на орбитали максимум 2 электрона с противоположными спинами.

Правило Клечковского: порядок заполнения 1s → 2s → 2p → 3s → 3p → 4s → 3d → 4p … Правило Хунда: сначала максимум неспаренных электронов. Это объясняет структуру таблицы Менделеева.
