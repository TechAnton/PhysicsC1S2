# Все короткие ответы — 42 билета

Выучи текст под каждым вопросом наизусть.

---

## 1. Электрический заряд и его свойства. Закон Кулона. Напряжённость электростатического поля. Принцип суперпозиции полей

Электрический заряд — свойство тела: бывает положительный и отрицательный. Одноимённые отталкиваются, разноимённые притягиваются. Заряд сохраняется и квантуется: q = ne, где e ≈ 1,6·10⁻¹⁹ Кл.

Закон Кулона: F = kq₁q₂/r² — сила между двумя точечными зарядами. Напряжённость E = F/q₀ показывает, с какой силой поле действует на единичный + заряд. Поле точечного заряда: E = kq/r². Если зарядов несколько — поля складываются по принципу суперпозиции: E = E₁ + E₂ + … (как векторы).

---

## 2. Теорема Гаусса для электростатического поля в интегральной форме. Поле бесконечно длинной заряженной нити

Теорема Гаусса: поток вектора E через любую замкнутую поверхность равен суммарному заряду внутри, делённому на ε₀: ∮E·dS = q_внутр/ε₀. Это удобно для симметричных задач — не нужно считать поле от каждого заряда отдельно.

Для бесконечной равномерно заряженной нити (линейная плотность λ, Кл/м) поле на расстоянии r: E = λ/(2πε₀r). Направление — радиально от нити (если λ > 0). У нити E убывает как 1/r, у точечного заряда — как 1/r². Для нахождения поля нити выбирают цилиндрическую гауссову поверхность.

---

## 3. Потенциал электростатического поля. Потенциал поля точечного заряда, системы зарядов. Связь потенциала и напряжённости поля

Потенциал φ — скалярная характеристика поля: потенциальная энергия единичного положительного заряда в данной точке. Единица — вольт (В). Для точечного заряда: φ = kq/r. Для нескольких зарядов потенциалы просто складываются (не как векторы!): φ = φ₁ + φ₂ + …

Связь с напряжённостью: E = −dφ/dr — поле направлено к убыванию потенциала. Разность потенциалов двух точек — это напряжение: U = φ₁ − φ₂. Эквипотенциальные поверхности перпендикулярны линиям E.

---

## 4. Диполь. Электрический момент диполя. Момент сил, действующих на диполь

Электрический диполь — два равных по модулю противоположных заряда ±q на расстоянии l. Электрический момент p = ql — вектор от − к +. Примеры: молекула HCl, поляризованная вода.

В однородном поле на диполь действует момент сил M = [p×E], он поворачивает диполь вдоль E; суммарная сила равна нулю. В неоднородном поле появляется ещё сила, втягивающая диполь в область сильного поля.

---

## 5. Проводники. Проводники в электростатическом поле. Явление электростатической индукции. Поле внутри заряженного проводника и у его поверхности. Электростатическая защита

В проводнике в равновесии электрическое поле внутри равно нулю (E = 0), весь заряд сосредоточен на поверхности, весь проводник — одна эквипотенциаль. У поверхности: E = σ/ε₀, направлено перпендикулярно поверхности.

Электростатическая индукция — перераспределение зарядов на проводнике во внешнем поле без контакта с источником. Суммарный заряд проводника при этом не меняется. Клетка Фарадея (замкнутый проводник или полая оболочка): внутри E = 0 — это электростатическая защита.

---

## 6. Электроёмкость уединённого проводника. Электроёмкость Земли

Электроёмкость C = Q/U — способность проводника накапливать заряд при заданном потенциале. Зависит от размера и формы, не от материала. Для изолированного шара: C = 4πε₀R.

Земля как проводящий шар имеет ёмкость около 700 мкФ и служит нулём потенциала при заземлении. Энергия заряженного конденсатора/проводника: W = CU²/2.

---

## 7. Взаимная ёмкость двух проводников. Электроёмкость плоского, сферического и цилиндрического конденсаторов. Соединения конденсаторов

Конденсатор — два проводника, разделённые диэлектриком. Взаимная ёмкость C = Q/U. Плоский конденсатор: C = ε₀εS/d (больше площадь и ε, меньше d — больше C).

Соединение конденсаторов — наоборот резисторам! Параллельно: C = C₁ + C₂ (U одинаково). Последовательно: 1/C = 1/C₁ + 1/C₂ (Q одинаково). Диэлектрик увеличивает C в ε раз.

---

## 8. Электрический ток в проводнике. Сила и плотность тока. Сопротивление проводника. Закон Ома для однородного участка цепи

Электрический ток I = Q/t — упорядоченное движение зарядов (амперы). Сопротивление R = ρl/S зависит от материала (ρ), длины и сечения. Закон Ома для однородного участка: I = U/R.

Последовательно: R = R₁ + R₂. Параллельно: 1/R = 1/R₁ + 1/R₂. В металлах носители — электроны. Направление тока (условное): от + к −.

---

## 9. Сторонние силы. ЭДС. Закон Ома для неоднородного участка цепи. Частные случаи. Закон Джоуля–Ленца

Сторонние (неэлектростатические) силы в источнике создают ЭДС ε — работа на единичный заряд при прохождении через источник. Полная цепь: I = ε/(R + r), где r — внутреннее сопротивление источника.

Закон Джоуля–Ленца: Q = I²Rt — при прохождении тока выделяется тепло. Мощность: P = I²R = UI. Холостой ход: I = 0, U = ε. Короткое замыкание: R = 0, I = ε/r.

---

## 10. Магнитное поле. Примеры таких полей. Правило правой руки. Принцип суперпозиции магнитных полей

Магнитное поле создают движущиеся заряды (токи) и постоянные магниты. Магнитная индукция B (тесла) характеризует поле. Правило правой руки: у прямого провода — большой палец по I, пальцы обхватывают по B; у соленоида — пальцы по I, большой по B.

Примеры: провод B = μ₀I/(2πr), соленоид B = μ₀nI, виток в центре B = μ₀I/(2R). Суперпозиция: B = B₁ + B₂ + … (векторно). Линии B — замкнутые.

---

## 11. Закон Био–Савара–Лапласа. Поле кругового витка с током

Закон Био–Савара–Лапласа: каждый элемент провода dl с током I создаёт магнитное поле dB. Для произвольного провода интегрируют вклады всех элементов.

В центре кругового витка радиуса R: B = μ₀I/(2R). N витков: B = μ₀NI/(2R). Ближе к проводу поле сильнее. Направление B — правило правой руки по току в витке.

---

## 12. Сила Лоренца. Работа силы Лоренца

Сила Лоренца F = q[v×B] действует на заряд q, движущийся со скоростью v в поле B. Левая рука: v, B → F (для + заряда). Если v ∥ B, то F = 0.

Работа силы Лоренца равна нулю — сила перпендикулярна скорости, кинетическая энергия не меняется, меняется только направление. Траектория в поперечном поле — окружность: R = mv/(qB).

---

## 13. Сила Ампера. Закон Ампера. Физический смысл 1 А

Сила Ампера F = BIl sinα действует на проводник длиной l с током I в поле B. Левая рука: I, B → F. Это следствие силы Лоренца для носителей в проводе.

1 ампер определён так: сила между двумя параллельными проводами длиной 1 м с токами I₁ = I₂ = 1 А на расстоянии 1 м равна 2·10⁻⁷ Н/м. Электродвигатель работает за счёт силы Ампера.

---

## 14. Сила взаимодействия двух токов

Два параллельных провода с токами взаимодействуют через магнитные поля: каждый ток создаёт B, B действует на другой ток. Сила на единицу длины: F/l = μ₀I₁I₂/(2πr).

Токи в одном направлении — провода притягиваются. В противоположных — отталкиваются. Именно это взаимодействие лежит в основе определения ампера.

---

## 15. Диэлектрики. Электрическое поле в диэлектрике. Виды поляризации

Диэлектрик — изолятор, не проводит постоянный ток. Во внешнем поле молекулы поляризуются — появляются связанные заряды, поле внутри ослабляется: E = E₀/ε.

Два вида поляризации: смещённая (неполярные молекулы, сдвиг электронов) и ориентационная (полярные диполи поворачиваются, например H₂O). Конденсатор с диэлектриком: C увеличивается в ε раз.

---

## 16. Поляризованность. Теорема Гаусса для вектора поляризации. Диэлектрическая восприимчивость. Диэлектрическая проницаемость

Поляризованность P — дипольный момент на единицу объёма (Кл/м²). Связь с полем: P = ε₀χE, где χ — диэлектрическая восприимчивость.

Диэлектрическая проницаемость ε = 1 + χ. В диэлектрике E = E₀/ε. На границе диэлектрика появляются связанные заряды. Вода: ε ≈ 80.

---

## 17. Сегнетоэлектрики и их применение. Диэлектрический гистерезис. Пьезоэлектрики

Пьезоэлектрики: прямой эффект — сжатие даёт заряд (пьезозажигалка, УЗ-датчики); обратный — напряжение вызывает деформацию (кварцевые часы).

Сегнетоэлектрики сохраняют поляризацию после снятия поля («память»). Диэлектрический гистерезис — зависимость P от E по петле, площадь петли — потери энергии.

---

## 18. Намагниченность. Диамагнетики, парамагнетики, ферромагнетики

Намагниченность I — магнитный момент на единицу объёма. B = μ₀μH, где μ = 1 + χ_m — магнитная проницаемость.

Три класса: диамагнетики (μ < 1) — слабо выталкиваются из поля (Cu, вода); парамагнетики (μ > 1) — слабо втягиваются (Al, O₂); ферромагнетики (μ >> 1) — сильно втягиваются (Fe, сталь).

---

## 19. Ферромагнетизм. Классификация ферромагнитных материалов. Петля гистерезиса. Антиферромагнетики, ферримагнетики

Ферромагнетики имеют домены — области с одинаково направленными магнитными моментами. Мягкие магнетики (трансформаторы) — легко намагнитить и размагнитить. Твёрдые — постоянные магниты.

Петля гистерезиса B(H): Br — остаточная индукция, Hc — коэрцитивная сила. Антиферромагнетики — моменты антипараллельны, сумма ≈ 0. Ферримагнетики — неравные моменты (ферриты).

---

## 20. Законы геометрической оптики. Атмосферная рефракция. Явление полного внутреннего отражения

В однородной среде свет распространяется прямолинейно. Закон отражения: угол падения = углу отражения. Закон Снеллиуса: n₁sinα = n₂sinβ, где n = c/v — показатель преломления.

Полное внутреннее отражение: при переходе из более плотной среды (n₁ > n₂) и α > α₀, где sinα₀ = n₂/n₁, луч полностью отражается. Основа оптоволокна. Атмосферная рефракция — Солнце видно выше горизонта.

---

## 21. Когерентность световых волн. Проблема когерентности света. Способы получения когерентных волн

Когерентные волны имеют постоянную разность фаз и одну частоту. Обычный свет (лампа) некогерентен — фазы «пляшут», интерференция не видна.

Когерентность получают делением одного источника: схема Юнга (две щели), бипризма Френеля, отражение от тонкой плёнки, лазер. У лазера длина когерентности — метры.

---

## 22. Интерференция света. Условия максимума и минимума интерференции. Расчёт схемы Юнга

Интерференция — сложение когерентных волн: усиление (максимум) или ослабление (минимум). Максимум: разность хода Δ = kλ. Минимум: Δ = (2k+1)λ/2.

Опыт Юнга: две щели, на экране светлые и тёмные полосы. Расстояние между полосами Δx = λL/d (L — до экрана, d — между щелями). Центр — светлый максимум. Интерференция доказывает волновую природу света.

---

## 23. Интерференция света в тонких плёнках. Полосы равного наклона и полосы равной толщины

При отражении от тонкой плёнки два луча (от верхней и нижней границ) интерферируют. Разность хода примерно Δ ≈ 2nh (плюс возможный скачок фазы λ/2).

Полосы равного наклона — толщина h постоянна, меняется угол. Полосы равной толщины — угол постоянен, меняется h (клин, кольца Ньютона). Пример: радужные полосы на мыльном пузыре.

---

## 24. Просветление оптики. Оптические аберрации. Интерференция в природе и технике

Просветление: тонкое покрытие толщиной h = λ/(4n) гасит отражённый свет за счёт интерференции. Антибликовое покрытие на объективе.

Аберрации — искажения изображения: сферическая (края линзы фокусируют иначе) и хроматическая (разный n для разных цветов — радужная кайма). Интерференция в технике: интерферометры, контроль плоскости.

---

## 25. Кольца Ньютона

Кольца Ньютона — интерференция в воздушном зазоре между выпуклой линзой и плоским стеклом. Полосы равной толщины — толщина зазора h растёт с радиусом.

Радиус k-го тёмного кольца: r_k = √(kλR), где R — радиус кривизны линзы. Используют для контроля качества линз и измерения длины волны.

---

## 26. Дифракция света. Принцип Гюйгенса–Френеля. Примеры проявления. Дифракция Френеля и Фраунгофера. Метод зон Френеля

Дифракция — огибание светом препятствий и проникновение в тень. Принцип Гюйгенса–Френеля: каждая точка волнового фронта — источник вторичных волн, они интерферируют.

Дифракция Френеля — источник близко к препятствию. Фраунгофера — далеко (решётка, щель). Метод зон Френеля: чётные зоны гасят друг друга, нечётные усиливают.

---

## 27. Дифракция Френеля на круглом отверстии. Зонная пластинка

Волновой фронт перед круглым отверстием делят на зоны Френеля. На экране — дифракционные кольца. Если открыта только первая зона — максимум в центре.

Зонная пластинка закрывает чётные зоны — свет усиливается примерно в 4 раза. Линзы Френеля в маяках — тот же принцип.

---

## 28. Дифракция Френеля на круглом препятствии

За круглым диском в геометрической тени на оси появляется светлое пятно Арago (Пуассона). Волны, огибающие край диска, интерферируют в фазе на оси.

Это классическое доказательство волновой природы света. Вокруг центрального пятна — тёмные и светлые кольца.

---

## 29. Дифракционная решётка. Разрешающая способность дифракционной решётки. Дифракция в технике

Дифракционная решётка — много параллельных щелей с периодом d. Условие максимума: d sinφ = kλ. Даёт узкие яркие максимумы — хорошее разделение спектра.

Разрешающая способность R = Nk = λ/Δλ, где N — число щелей. Применение: спектрометры, CD/DVD (штрихи как решётка).

---

## 30. Получение голограмм

Голограмма — запись интерференционной картины опорного и объектного лучей на светочувствительной пластинке. Нужен лазер (когерентный свет).

При освещении записанной голограммы опорным лучом восстанавливается объёмное изображение за счёт дифракции. Записывается и амплитуда, и фаза волны.

---

## 31. Дисперсия света. Нормальная и аномальная дисперсия

Дисперсия — зависимость показателя преломления n от длины волны λ. Нормальная дисперсия: n увеличивается при уменьшении λ (фиолетовый преломляется сильнее) — призма, радуга.

Аномальная дисперсия — вблизи полосы поглощения вещества dn/dλ > 0. Хроматическая аберрация линз — следствие дисперсии.

---

## 32. Поляризация света. Закон Малюса

Естественный свет — колебания E во всех плоскостях. Поляризованный — E в одной плоскости. Поляризатор пропускает одну плоскость колебаний.

Закон Малюса: при прохождении через второй поляризатор I = I₀cos²α, где α — угол между осями. При α = 90° (скрещенные поляризаторы) — полное гашение.

---

## 33. Поляризация света. Закон Брюстера

При отражении от диэлектрика при угле Брюстера отражённый свет полностью поляризован. Условие: tanα_B = n₂/n₁. Отражённый и преломлённый лучи перпендикулярны (α_B + β = 90°).

Для воды α_B ≈ 53°. Поляризационные очки гасят блики с воды и дороги — отражённый свет поляризован.

---

## 34. Поглощение света. Закон Бугера–Ламберта

При прохождении через поглощающую среду интенсивность экспоненциально уменьшается: I = I₀e^(−κx), где κ — коэффициент поглощения, x — толщина.

Объясняет красный закат (длинный путь в атмосфере), цветные стёкла, работу спектрофотометра. Пропускание T = I/I₀.

---

## 35. Тепловое излучение. Законы излучения абсолютно чёрного тела

Абсолютно чёрное тело (АЧТ) — идеальный поглотитель и излучатель всех длин волн. Закон Стефана–Больцмана: полная мощность излучения E = σT⁴ (T в Кельвинах!).

Закон Вина: λ_max·T = b ≈ 2,9·10⁻³ м·К — при нагреве пик спектра смещается к коротким волнам (металл: красный → белый). Реальное тело: E = εσT⁴.

## 36. Фотоэффект и его законы

Фотоэффект — выбивание электронов из металла под действием света. Уравнение Эйнштейна: hν = A_вых + E_k. Три закона: 1) число электронов ∝ яркость; 2) E_k зависит только от частоты ν; 3) есть красная граница ν₀.

Классическая физика не объясняла зависимость E_k от ν. Фотоэффект доказывает квантовую природу света (фотоны). Примеры: солнечные батареи, фоторезистор.

---

## 37. Эффект Комптона

Рассеяние рентгеновских фотонов на свободных электронах: длина волны увеличивается на Δλ = (h/(m_e c))(1−cosθ) = Λ(1−cosθ), Λ ≈ 2,43 пм.

Классическая теория предсказывала Δλ = 0. Комптон доказал, что фотон имеет импульс p = h/λ и отдаёт часть энергии электрону. Ещё одно доказательство корпускулярной природы света. При угле рассеяния θ = 180° сдвиг длины волны максимален: Δλ = 2Λ.

## 38. Корпускулярно-волновой дуализм света. Волны де Бройля

Свет проявляет и волновые свойства (интерференция, дифракция), и корпускулярные (фотоэффект, Комптон). Дуализм — обе картины дополняют друг друга.

Де Бройль: любая частица с импульсом p имеет волну длины λ = h/p. Электроны дифрагируют на кристаллах (опыт Дэвиссона–Джермера) — волновая природа материи. Электронный микроскоп — короткая λ → высокая резкость.

## 39. Теория Бора. Атом водорода по Бору

Бор постулировал стационарные орбиты, на которых электрон не излучает. Квантование момента: mvr = nh/(2π). Энергия: E_n = −13,6/n² эВ.

Излучение только при переходах между орбитами: hν = E_i − E_f. Объяснил линейчатый спектр водорода (серия Бальмера — переходы на n = 2). Модель полуклассическая, работает для H.

## 40. Квантовая теория атомов. Правила заполнения таблицы Менделеева

Электроны занимают орбитали (s, p, d, f). Принцип Паули: на орбитали максимум 2 электрона с противоположными спинами.

Правило Клечковского: порядок заполнения 1s → 2s → 2p → 3s → 3p → 4s → 3d → 4p … Правило Хунда: сначала максимум неспаренных электронов. Это объясняет структуру таблицы Менделеева.

## 41. Опыты Резерфорда. Состав ядра атома. Изотопы. Энергия связи ядра. Дефект массы

Опыт Резерфорда: α-частицы на тонкой золотой фольге — большинство прошли, немногие отскочили → ядро компактное (~10⁻¹⁵ м), почти вся масса в нём.

Ядро: Z протонов, N нейтронов, массовое число A = Z + N. Изотопы — один Z, разный N (¹²C и ¹⁴C). Дефект массы Δm, энергия связи E_св = Δm·c². 1 а.е.м. ≈ 931 МэВ.

## 42. Стабильные и нестабильные ядра. Радиоактивность. Закон радиоактивного распада. Период полураспада

Радиоактивность — самопроизвольный распад нестабильных ядер. Виды излучения: α (ядро He, Z−2), β⁻ (электрон, Z+1), γ (фотон, Z без изменений).

Закон распада: N = N₀e^(−λt) = N₀·2^(−t/T½). Период полураспада T½ — время, за которое распадается половина ядер. T½ = 0,693/λ. T½ не зависит от начального количества. Пример: углерод-14 для радиоуглеродного датирования (T½ = 5730 лет).
