# 42. Радиоактивность. Закон распада. Период полураспада

Стабильные и нестабильные ядра. Радиоактивность. Закон радиоактивного распада. Период полураспада

---

Радиоактивность — самопроизвольный распад нестабильных ядер. Виды излучения: α (ядро He, Z−2), β⁻ (электрон, Z+1), γ (фотон, Z без изменений).

Закон распада: N = N₀e^(−λt) = N₀·2^(−t/T½). Период полураспада T½ — время, за которое распадается половина ядер. T½ = 0,693/λ. T½ не зависит от начального количества.

На экзамене: N = N₀·2^(−t/T½), T½ — полураспад, α β γ. Пример: ¹⁴C для датирования (T½ = 5730 лет).
