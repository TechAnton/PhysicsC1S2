# Краткие конспекты (lectures_shorts)

Минимум для проходного ответа на экзамене: **2–3 абзаца** на билет.

## Как пользоваться

1. Прочитай абзацы вслух 2–3 раза.
2. Запомни **формулу** из второго абзаца.
3. Третий абзац — что сказать, если спросят.

## Структура

| Папка | Что внутри |
|-------|------------|
| `lectures_shorts/` | кратко (здесь) |
| `lectures/` | подробно |
| `exam-prep/` | шпаргалки, HTML |

## Приоритет

Сначала билеты с 🔴 в [карте билетов](../exam-prep/03_карта_билетов.md) — их 22 из 42.

## Если растерялся на экзамене

Скажи: **что это** (1 фраза) + **одну формулу** + **один пример**.
