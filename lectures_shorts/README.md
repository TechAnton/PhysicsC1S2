# Краткие конспекты (lectures_shorts)

Минимум для проходного ответа: **2 абзаца** на билет — выучи наизусть.

## Как пользоваться

1. Открой **00_все_короткие_ответы.md** — все билеты в одном файле.
2. Прочитай текст под вопросом вслух 3–5 раз.
3. Повторяй по разделам: сегодня 1–14, завтра 15–28, послезавтра 29–42.

|-------|------------|
| `lectures_shorts/` | кратко (здесь) |
