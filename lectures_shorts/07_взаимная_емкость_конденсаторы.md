# 7. Взаимная ёмкость. Конденсаторы. Соединения

Взаимная ёмкость двух проводников. Электроёмкость плоского, сферического и цилиндрического конденсаторов. Соединения конденсаторов

---

Конденсатор — два проводника, разделённые диэлектриком. Взаимная ёмкость C = Q/U. Плоский конденсатор: C = ε₀εS/d (больше площадь и ε, меньше d — больше C).

Соединение конденсаторов — наоборот резисторам! Параллельно: C = C₁ + C₂ (U одинаково). Последовательно: 1/C = 1/C₁ + 1/C₂ (Q одинаково). Диэлектрик увеличивает C в ε раз.

На экзамене: назови формулу плоского конденсатора и правила соединения. Запомни: параллельно — как резисторы последовательно, и наоборот.
