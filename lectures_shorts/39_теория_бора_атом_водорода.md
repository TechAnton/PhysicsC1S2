# 39. Теория Бора. Атом водорода по Бору

---

Бор постулировал стационарные орбиты, на которых электрон не излучает. Квантование момента: mvr = nh/(2π). Энергия: E_n = −13,6/n² эВ.

Излучение только при переходах между орбитами: hν = E_i − E_f. Объяснил линейчатый спектр водорода (серия Бальмера — переходы на n = 2). Модель полуклассическая, работает для H.
